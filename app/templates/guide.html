02 · 요청자

울산공장 — 이정인 매니저

재발주를 처음 트리거하는 역할 계정 haon

포장지 재고가 부족해지거나 표시사항 등을 고쳐야 할 때 이 화면에서 재발주 건을 등록합니다. 이후 진행 상황은 대시보드에서 실시간으로 확인할 수 있어, 확인차 메일을 보낼 필요가 없습니다.

  1. 로그인 후 대시보드 확인

    로그인하면 바로 대시보드가 뜨고, 내가 등록한 모든 요청이 요청번호·품목·사유·상태·등록일 순서로 표에 나열됩니다.

    상태 배지 읽는 법 — 1차검토중 검토 대기 · 디자인수정중 수정 진행 중 · 최종검수중 연구소 검수 대기 · 완료 전달까지 끝남 · 취소됨 중단된 건
    상태 옆 "진행 흐름" 열에 1차검토 → 최종검수 → 전달대기 → 완료 점이 표시되어, 배지 문구를 안 읽어도 지금 어느 단계인지 한눈에 보입니다.
    대시보드에는 진행 중인 건만 표시됩니다. 완료되거나 취소된 건은 목록이 계속 길어지지 않도록 자동으로 빠지며, 상단 "완료·취소 이력" 메뉴에서 요청번호·품목명으로 검색해 언제든 다시 찾아볼 수 있습니다.

  2. 새 재발주 요청 등록

    대시보드 상단의 "+ 재발주 요청 등록" 버튼을 누르고, 품목(품목코드-품목명)과 재발주 요청 사유(재고 소진(임박) / 표시사항 등 수정 필요)를 선택한 뒤 등록합니다.

    품목이 많아 목록이 길면, 선택창 위 검색창에 품목명이나 품목코드 일부를 입력해 목록을 좁힐 수 있습니다.
    사유 선택 아래 "요청사항" 칸에 구체적인 내용(예: 어떤 표시사항을 어떻게 고쳐야 하는지)을 간단히 적어두면, 상세 페이지와 이력에 함께 남아 담당자들이 참고할 수 있습니다(선택 입력).
    같은 품목에 이미 진행 중인 건이 있으면 새로 만들어지지 않고 기존 건으로 자동 이동합니다 — 중복 등록을 막기 위한 장치이니 당황하지 않아도 됩니다.

  3. 진행 상황 확인

    요청번호를 클릭하면 상세 페이지로 들어갑니다. 여기서 현재 연결된 파일, 지금 누구 차례인지, 그리고 등록 시점부터 지금까지의 전체 이력(타임라인)을 시간순으로 볼 수 있습니다.

  4. 필요하면 요청 취소

    완료되기 전이라면 언제든 대시보드나 상세 페이지의 "요청 취소" 버튼으로 직접 취소할 수 있습니다. 클릭하면 사유를 묻는 창이 뜨며, 사유를 입력해야만 취소가 처리됩니다.

  5. 완료된 건의 최종 파일 받기

    상태가 완료로 바뀌면 박현경 팀장이 최종 파일을 전달 처리한 것입니다. 상세 페이지의 "현재 파일" 영역에서 최종 승인본 배지가 붙은 AI·JPG 파일을 그대로 다운로드해 인쇄에 사용하면 됩니다.

    상단 품목·파일 메뉴에서 품목명을 검색하면 과거 버전과 승인 이력도 언제든 다시 확인할 수 있습니다.
03 · 1차 검토·관리 창구

브랜드기획팀 — 박현경 팀장

최종본 판단, 최종 승인 파일 관리 및 전달 창구 계정 isis9 (부재 시 대체 shindeok_kim)

신규 요청의 최종본 여부를 가장 먼저 판단하고, 연구소 승인이 끝난 파일을 관리해 울산공장에 전달하는 핵심 창구 역할입니다. 대시보드에 "내가 처리해야 할 건"이 항상 최상단에 뜹니다.

  1. 1차검토중 건 처리

    대시보드에서 1차검토중 건을 열어 현재 파일을 확인합니다. 그동안 구두·메신저 등 다른 채널로 접수해둔 오타·수정요청이 있다면 이번 판단에 반영하세요.

    최종본이 맞으면 "최종본 확인 → 최종검수 요청"을 눌러 연구소로 넘기고, 손볼 곳이 있으면 수정 지시사항을 적고 "수정 필요 → 디자인 요청"을 누릅니다.

  2. 최근 승인 이력이 있으면 검수 생략

    해당 파일이 최근 3개월 이내에 연구소 승인을 받은 적이 있으면, 최종본 확인 화면에 "최근 3개월 이내 승인 이력 있음" 체크박스가 나타납니다. 체크하고 제출하면 연구소 검수 없이 바로 완료 처리됩니다.

  3. 전달대기 건 — 최종 파일 전달

    연구소 승인이 끝나면 건이 전달대기 상태로 넘어옵니다. 내용에 문제가 없으면 "최종파일 전달·완료 처리"를 눌러 울산공장에 전달을 완료하세요.

  4. 필요하면 직접 반려

    최종검수 대기 중인 건에서 문제를 먼저 발견했다면, 연구소 판단을 기다리지 않고 상세 페이지에서 바로 사유를 입력해 반려할 수 있습니다 — 건은 1차검토중으로 되돌아갑니다.

    반대로 전달대기 건에서 문제가 보이면 "승인 취소"로 최종검수 단계로 되돌릴 수 있습니다. 다만 승인 자체와 수정필요(경미) 판정은 연구소 전용 권한이라 이 계정에는 버튼이 뜨지 않습니다.

  5. 대시보드에서 바로 반려·취소

    상세 페이지에 들어가지 않아도, 대시보드 목록의 행에서 바로 "반려(취소)" 또는 "승인 취소" 버튼으로 처리할 수 있습니다. 1차검토중 건을 반려하면 그 이전 단계가 없으므로 요청 자체가 취소됨으로 종료됩니다.

  6. 부재중 설정 (대체 담당자 라우팅)

    휴가·출장 등으로 자리를 비울 때는 화면 상단의 "부재중 설정"을 눌러두세요. 켜져 있는 동안에는 김신덕 본부장 대시보드에도 동일한 대기 건이 노출되어 대신 처리할 수 있습니다. 복귀하면 같은 버튼(부재중 해제)으로 끄면 됩니다.

    부재중으로 설정해두면, 그 사이 등록되는 건은 대체 담당자에게도 이메일·문자·브라우저 알림이 동일하게 갑니다 — 본인 것과 별도로 확인 연락을 따로 할 필요가 없습니다.

  7. 일괄 업로드 · 일괄 다운로드

    상단 "일괄 업로드/다운로드" 메뉴에서, 기존에 보유 중인 포장지 파일들을 한 번에 이관하거나(품목코드 매핑용 엑셀 동반 가능), 여러 품목의 최종 승인본을 zip 하나로 묶어 이력 목록(manifest.csv)과 함께 다운로드할 수 있습니다.

    매핑표를 처음 만든다면 "빈 매핑표 양식 다운로드"로 열을 그대로 맞춘 엑셀을 받아서 채우면 됩니다.
04 · 디자인 수정

디자인팀 — 최효진 차장

지적사항에 따른 파일 수정 담당 계정 guychj

박현경 팀장이 "수정 필요"로 넘긴 건만 이 계정 대시보드에 나타납니다. 수정한 파일을 올리면 자동으로 새 버전이 만들어지고, 별도 확인 메일 없이 1차검토로 재확인 요청이 갑니다.

  1. 배정된 수정 건 확인

    대시보드에서 디자인수정중 건을 열면, 박현경 팀장이 남긴 수정 지시사항을 그대로 확인할 수 있습니다.

  2. 수정 파일 업로드

    지시사항대로 수정한 AI 파일과 JPG 파일을 함께 첨부하고, 무엇을 고쳤는지 간단히 메모한 뒤 "수정 파일 업로드"를 누릅니다.

    AI·JPG 둘 다 첨부해야 제출됩니다. 업로드된 파일은 자동으로 다음 버전(v2, v3…)으로 기록되고, 건은 다시 1차검토중으로 돌아가 박현경 팀장의 재확인을 기다립니다.

  3. 잘못 배정된 건은 반려

    배정된 수정 건이 우리 팀 소관이 아니거나 진행할 수 없는 사정이 있다면, 사유를 입력해 반려할 수 있습니다. 반려하면 건은 1차검토중으로 되돌아갑니다.

05 · 최종 검수 · 연구소

연구소 — 조현종 소장

표시사항 등 법적 요건 최종 검수·승인 판정 계정 hjcho

박현경 팀장이 최종본으로 확인해 넘긴 건만 대시보드에 뜹니다. 승인과 수정필요(경미) 판정은 이 역할만 내릴 수 있는 전용 권한입니다.

  1. 최종검수 대기 건 확인

    대시보드에서 최종검수중 건을 열어 현재 파일(AI·JPG)을 내려받아 표시사항 등 법적 요건을 검토합니다.

  2. 세 가지 중 하나로 처리

    승인 — 문제 없으면 승인합니다. 해당 파일이 즉시 최종 승인본으로 잠기고(더 이상 수정·삭제 불가), 박현경 팀장에게 울산공장 전달 처리가 필요하다는 알림이 갑니다.

    수정 필요(경미) — 보완할 부분은 있지만 다시 만들 정도는 아닐 때 사용합니다. 사유를 적으면 1차검토중으로 되돌아갑니다.

    반려 — 부적합 판정입니다. 사유를 반드시 적어야 하며, 이 사유는 담당자 전원에게 그대로 전달되고 이력에 영구히 남습니다.

    사유 없이 수정 필요·반려는 제출되지 않습니다 — 왜 되돌아갔는지 나중에 다시 설명할 필요가 없도록 하는 장치입니다.
06 · 공통 안내

모든 역할이 알아두면 좋은 것

알림은 어디서 확인하나요

내 차례가 되면 화면 상단 "알림함"에 실시간으로 표시됩니다(숫자 배지). 등록된 이메일과 휴대폰번호로 이메일·문자 알림도 실제로 발송되며, 부재중 대체 담당자를 포함해 모든 처리 단계(등록·수정요청·검수요청·승인·반려·취소·전달완료)에서 동일하게 나갑니다. 문자를 받으려면 관리자에게 요청해 본인 프로필에 휴대폰번호가 등록되어 있어야 합니다.

브라우저(휴대폰) 알림 받기

화면 상단 사용자 이름 옆에 "브라우저 알림 받기" 버튼이 보이면 눌러서 허용해두세요. 이후 시스템을 직접 열어보지 않아도 내 차례가 될 때마다 기기 알림으로 바로 받을 수 있습니다. 아이폰(Safari)에서는 먼저 홈 화면에 추가 후 그 아이콘으로 실행해야 알림 허용 창이 뜹니다.

이력(타임라인)은 왜 중요한가요

모든 건의 상세 페이지 하단에는 등록부터 지금까지의 모든 조치(등록·검토·수정·검수·반려·전달)가 누가·언제·무슨 내용으로 처리했는지 빠짐없이 시간순으로 남습니다. 진행 경위를 다시 설명할 필요 없이 이 화면 하나로 확인하면 됩니다.

지난 건은 어디서 찾나요

모든 역할의 대시보드는 진행 중인 건만 보여줍니다. 완료·취소된 과거 건은 상단 "완료·취소 이력" 메뉴에서 요청번호·품목명·품목코드로 검색하고, 완료/취소 상태로도 좁혀볼 수 있습니다.

버튼이 안 보여요

처리 버튼은 현재 단계 + 내 역할이 맞을 때만 나타납니다. 예를 들어 최종검수중 건에서 승인·수정필요(경미) 버튼은 연구소(조현종 소장) 계정에서만 보이며, 다른 계정에는 원천적으로 표시되지 않습니다 — 권한이 나뉘어 있는 정상적인 동작입니다.

반려·취소 사유는 왜 꼭 적어야 하나요

사유를 적지 않으면 시스템이 제출 자체를 막습니다. 되돌리는 이유가 이력에 남아야 나중에 같은 건을 다시 볼 담당자가 맥락을 알 수 있기 때문입니다.

휴대폰에서도 그대로 쓸 수 있나요

네, PC와 동일한 주소로 휴대폰 브라우저에서도 이용할 수 있습니다. 화면이 좁아지면 상단 메뉴가 ≡ 버튼(햄버거 메뉴)으로 접히고, 대시보드·품목·파일 등 표 형태 화면은 각 행이 카드 형태로 자동 전환되어 좌우로 긴 표를 스크롤할 필요가 없습니다.

대시보드의 "진행 흐름"은 뭔가요

모든 역할의 대시보드 목록에 요청번호별로 1차검토 → 최종검수 → 전달대기 → 완료 점이 표시됩니다. 지나온 단계는 채워진 초록 점, 지금 단계는 테두리로 강조, 아직 안 온 단계는 흐리게 보입니다. 디자인수정중인 건은 1차검토 점 아래 "↳ 디자인수정중"으로, 취소된 건은 전체가 회색으로 표시됩니다 — 상태 배지를 읽지 않아도 진행 상황을 한눈에 볼 수 있습니다.
